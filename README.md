# Zemi

**Zemi** is a trust-based escrow platform designed for online sellers in Kenya. It protects both buyers and sellers by holding payments securely until delivery is confirmed, eliminating fraud and payment delays while ensuring smooth, secure transactions.

## Key Features

- **Payment Protection**: Funds held securely in escrow until delivery confirmation
- **Verified Delivery**: Buyers can inspect and verify products before payment release
- **Seller Guarantee**: Guaranteed payment once delivery is confirmed
- **Instant Release**: Quick payment processing once both parties are satisfied

---

*No fraud, no delays, just smooth payments.*
